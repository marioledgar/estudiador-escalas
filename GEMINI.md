# GEMINI.md

Este proyecto utiliza JavaScript para gestionar dinámicamente el contenido de la interfaz.

## Convenciones

- La interfaz inicial se genera mediante la función `pantallaInicial()` en `main.js`.
- Se prefiere el uso de `innerHTML` para bloques grandes de HTML estático convertidos a JS.
- **Nunca** cambies nada que no se te pida. Mantén los ids, names, textContents... en los refactors.
